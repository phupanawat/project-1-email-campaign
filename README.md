# Project 1 Email Campaign

**Live site (GitHub Pages):** https://phupanawat.github.io/project-1-email-campaign/

A responsive HTML email for Northstar Travel's "Fall Weekend Escapes" campaign.

## What's included

- **Two-column component:** "Featured stays" cards.
- **Three-column component:** "Trending this fall" destinations.
- **Responsive layout:** below 620px both multi-column rows stack into one column and text sizes shrink.
- **Interactivity:** hover/focus effects on the buttons, nav links, text links, footer links and card images.
- **Keyframe animations:** flying plane (translate + rotate), wiggling promo badge (rotate), glowing button (background-color + box-shadow), sliding color stripe (background-position) and sliding panels (translateY). No opacity or scale.
- **Checked-box technique:** "Find your vibe" tabs built with radio buttons, labels and divs. Clients that strip form inputs fall back to showing all three panels.
